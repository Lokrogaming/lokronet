LokroNet v0.1.0 (MVP)

Meshnet mit Terminal-CLI. Installieren auf Linux (amd64/arm64):

curl -fsSL https://net.lokro.dev/install | sudo bash

Danach (als normaler User, nicht root):

lokronet setup --rendezvous http://DEIN-SERVER:8787
lokronet daemon
